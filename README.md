## 🤖 Built with Claude
Lately I've been pairing with [Claude Code](https://claude.com/claude-code) on a lot of the small, self-hosted tools that run my home and my week. Me on ideas and reviews, Claude on the typing:

- ⏰ **cronos**: a tiny Node.js scheduler with a web dashboard that runs my automations: Dependabot auto-merges, TLS certificate expiry alerts, transport card reminders
- 🃏 **[estim8](https://github.com/fabrice404/estim8)**: T-shirt sizing, a test suite run before every deploy, and a round of bug fixes (zero votes, server crashes, player sync)
- 📹 **Home CCTV**: watch my cameras live in the browser, with go2rtc turning RTSP into low-latency WebSocket streams
- 🎁 **Wishlist**: a gift list built from a text file of product links, where guests can reserve a gift
- 📚 **Mes devoirs**: a homework practice app with English vocabulary drills
- 🛒 **Grocery receipts**: a Playwright scraper that downloads supermarket invoices and charts the price history of everything I buy
- 💶 **Budget**: my personal finance app, now with bank imports and Docker healthchecks
- 🔒 **apache-certbot**: an Apache reverse proxy in Docker with automatic Let's Encrypt certificates

Turns out "automate the boring stuff" gets a lot faster when someone else writes the boilerplate.
